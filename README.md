# Adossi Fred William, Portfolio

Personal portfolio website for **Adossi Fred William**, Software Engineer and Machine Learning Engineer.

Live site: https://adossi-design.github.io

## About

A fast, dependency-free, single-page portfolio built with plain HTML, CSS, and JavaScript, so it deploys instantly on GitHub Pages with no build step.

### Features
- Responsive design (desktop to mobile)
- Dark and light theme toggle (remembers your choice)
- Scroll-reveal animations
- 26 featured projects with live GitHub links and category filtering (ML/AI, Mobile, Full-Stack, Foundations)
- Coursework strip linking the rest of 40+ public repositories
- Sections: About, What I Do, Skills, Projects, Experience, Education, Contact

## Tech
Pure HTML5, CSS3, and vanilla JavaScript. No frameworks, no dependencies.

## Deploy (GitHub Pages)
This repo is named `Adossi-design.github.io`, which GitHub publishes automatically as a user site:

1. Push this repo to `https://github.com/Adossi-design/Adossi-design.github.io`
2. In the repo, go to Settings then Pages, and set Source to the `main` branch (root).
3. The site goes live at `https://adossi-design.github.io` within a minute.

## Local preview
Open `index.html` in a browser, or run a static server:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```
